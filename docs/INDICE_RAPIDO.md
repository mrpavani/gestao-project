## 🎁 Ficheiro de Dicas

### Tip 1: Use container para 1300px
```html
<div class="container mt-5 mb-5">
    <!-- seu conteúdo aqui -->
</div>
```

### Tip 2: Use btn-primary para ação principal
```html
<a href="#" class="btn btn-primary btn-lg">Ação Principal</a>
```

### Tip 3: Use btn-outline-* para ações secundárias
```html
<a href="#" class="btn btn-outline-primary btn-sm">Ver</a>
```

### Tip 4: Use gap-2, gap-3, etc para espaçamento
```html
<div class="d-flex gap-2">
    <button>Item 1</button>
    <button>Item 2</button>
</div>
```

### Tip 5: Procure sempre no arquivo style.css
```
assets/css/style.css → Seção === ESTILOS DE BOTÕES ===
```
